色の付いた〔　〕の部分を、実際の内容に置き換えて使ってください。

よく使う頼み方は残しておく

うまくいった頼み方は、プロジェクトの指示やスキルにしておくと、次から一言で頼めます。

社内ルールに沿って

お客様の個人情報や社外秘の情報は、社内ルールに沿って扱ってください。

「頼む」と「相談する」

どの項目にも、2種類のプロンプトを載せています。迷ったときは「相談する」から始めてください。

頼む

やることが決まっているときに。作ってほしいものと条件を伝えます。

相談する

もっと良いやり方がありそうなとき、どう頼めばいいか迷うときに。目的と状況を伝えて、提案や質問をもらいます。

どんな場面でも使える、相談のひとこと

方法をたずねる
〔やりたいこと〕をしたいです。もっと良いやり方があれば提案してください。
質問してもらう
うまく進めるために、必要なことを一つずつ質問してください。
選択肢をもらう
案を2〜3つ出して、それぞれの良いところと気をつけることを教えてください。
作る前に確かめる
作り始める前に、どう進めるつもりか先に教えてください。
もう一段よくする
今の答えを、もっと良くするとしたら、どこをどう変えますか。
目的から考え直す
そもそも何のためにこの作業をしているか、から一緒に整理させてください。

A　すぐ試せる

チャットに貼るだけで使えます。ファイルは添付してください。

A1

英語のメールを訳して、返信を作る

チャット

ご要望：先方からきたメールを翻訳し、返したい内容とニュアンスを伝えて返信文を作成。日本語訳も同時に表示

PROMPT · 頼む
取引先から届いた英語のメールを下に貼ります。
まず日本語に訳してください。
そのあと、次の内容で返信を作ってください。返信は、英文と日本語訳を並べて表示してください。

伝えたいこと：〔例：部品の入荷が遅れていて、納期を1週間延ばしたい〕
ニュアンス：〔例：丁寧に、でもはっきりと〕

---
〔ここに届いたメールを貼る〕
PROMPT · 相談する
英語のメールが届いて、返信に迷っています。相手とは〔長い付き合い／初めての取引〕で、〔伝えたいこと〕を伝えたいです。
角が立たないようにするには、どんなトーンで、何から書けばいいですか。案を2つ出して、違いも教えてください。

言い回しを変えたいときは「もう少しやわらかく」「もっと短く」と続けて頼めます。

A2

請求書を送るメールを作る

チャット

ご要望：提出先に合わせて、注文番号や船名を含めた宛先・件名・CC・本文をコピペできる状態で作成

PROMPT · 頼む
添付した請求書を送るメールを作ってください。
宛先・件名・CC・本文を、それぞれ分けて、そのままコピーできる形で出してください。

・件名と本文には、注文番号と船名を必ず入れる
・提出先：〔部門名〕（宛先：〔メールアドレス〕、CC：〔メールアドレス〕）
・英文で送る場合は、英文と日本語訳を並べる
・金額と注文番号が請求書と合っているか、最後に確認する
PROMPT · 相談する
請求書を送るメールを、提出先ごとに毎回作っています。部門によって宛先やCCが違い、英文で送ることもあります。
もっと楽に、間違いなく作れるやり方があれば提案してください。必要なことは質問してください。

提出先ごとの宛先・CCを一覧にして添付しておくと、提出先を選ぶだけで済みます。うまくいったら「今の手順をスキルにして」と頼んでください。

PROMPT · 相談する

B　フォルダで任せる

デスクトップアプリで「Work」を選び、ファイルの入ったフォルダを開いて許可してから頼みます。

B1

見積から納品書・請求書を作る

Work（フォルダ）

ご要望：見積と納品書・請求書の書式が異なる場合の転記を自動化したい

PROMPT · 頼む
このフォルダの見積データと請求書の書式を読んで、次の順に進めてください。
1. Excelで請求書を作り、品名・数量・単価・税額・合計を見積と照合する
2. 請求書をPDFで同じフォルダに保存し、文字切れやページ分割がないか確認する
3. ブラウザでGmailを開き、〔宛先〕宛てに送付メールを書く（件名と本文に注文番号と船名を入れる）
4. PDFを添付し、送信はせずに下書き保存する
終わったら、照合と確認の結果を教えてください。
PROMPT · 相談する
見積から請求書・納品書を作るとき、書式が違うので転記しています。
このフォルダのファイルを見て、ミスなく早く作るにはどんな進め方がいいか提案してください。作業はまだ始めないでください。

3と4は、ブラウザを操作する機能（コンピューターユース）を使います。メールは必ず下書きで止め、金額と宛先を人の目で確認してから送ってください。うまくいったら「今の手順をスキルにして」と頼むと、次からは一言で進められます。

B2

過去の見積から、単価を調整した見積を作る

Work（フォルダ）

ご要望：過去の見積から、何％幅でアップ、総額がおおよそこの金額になるように単価を調整した見積の作成

PROMPT · 頼む
このフォルダの「〔過去の見積のファイル名〕.xlsx」をもとに、新しい見積を作ってください。
・各品目の単価を〔5〜8〕％の範囲で上げる
・総額がおおよそ〔金額〕円になるように調整する
・端数は〔100円単位〕でそろえる
・元のファイルは変更せず、新しいファイルで作る
最後に、品目ごとの「元の単価／新しい単価／上げ幅（％）」の一覧と、合計の確認結果を出してください。
PROMPT · 相談する
過去の見積をもとに、全体を値上げした見積を作りたいです。
どの品目をどのくらい上げるのが自然か、考え方の選択肢を出してください。決める前に気をつけることも教えてください。

計算はAIにも確認させますが、最終の金額は必ずご自身で確かめてください。

C　仕組みを整える

まずはファイルを渡して試せます。毎日自動で見張るには、データの置き場所と定期実行の仕組みづくりが必要です。

この頼み方が固まったら、スキルにして毎週同じ形で出せるようにします。毎日自動で確認する形は、研修後のご相談で一緒に設計しましょう。

D　図面・CAD

寸法まで正確な作図は、CADソフト側の機能が中心です。ChatGPTは、確認・整理・自動化の手順づくりで手伝えます。

D1

寸法の一括記入を自動化する方法を調べる

チャット

ご要望：図面上に寸法を一括表記して作業時間を短縮したい

PROMPT · 頼む
〔CADソフトの名前とバージョン〕を使っています。
図面上の〔寸法の種類：例 穴位置の寸法〕を一括で記入する作業を自動化したいです。
このソフトで使える自動化の方法（スクリプト、マクロ、標準機能など）があるか教えてください。
あれば、手順とサンプルを、初めての人にも分かるように説明してください。
PROMPT · 相談する
図面に寸法を入れる作業に時間がかかっています。〔CADソフトの名前〕を使っています。
手作業を減らす方法として、どんな選択肢がありますか。手軽なものから順に教えてください。

自動化を試すときは、必ず図面のコピーで行ってください。使えるかどうかはCADソフトによって異なります。

D2

寸法の書き漏れ・重複を確認する

チャット

ご要望：表記漏れや重複寸法が無いかチェックしたい

PROMPT · 頼む
図面のPDF（または画像）を添付します。
寸法の書き漏れがありそうな箇所と、同じ寸法が重複していそうな箇所を指摘してください。
確実でないものは「要確認」として分けてください。
PROMPT · 相談する
図面の寸法の書き漏れや重複を、もっと確実に防ぎたいです。
チェックのやり方や、チェックリストの作り方で良い方法があれば提案してください。

AIも見落とすことがあります。最終確認の代わりではなく、確認の補助として使ってください。

D3

図面を見やすくする

チャット
